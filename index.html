¿Qué es un encoder?

Un encoder es un sensor que convierte una posición (angular o lineal) en una señal digital. Así, un microcontrolador puede saber cuánto se movió algo y en qué dirección.

Es una entrada del sistema: el mundo físico (giro) → información digital (pulsos o códigos).

💡 Analogía: el encoder incremental es como contar pasos: sabes cuántos diste, pero si te caes tienes que regresar al inicio. El absoluto es como un GPS: siempre sabe dónde estás.

Tipos de encoder (da clic 👆)

Entrega pulsos cada vez que el eje gira, y el sistema los cuenta.

  • Usa 2 canales (A y B) desfasados 90° (cuadratura) para saber la dirección del giro.
  • Se mide en PPR (pulsos por revolución).
  • ⚠️ Al apagarse olvida la posición: necesita un punto de referencia.

💰 BaratoAltaPerilla de volumen, rueda del mouse, KY-040 de Arduino

Entrega un código único para cada posición. Cada punto del giro tiene su propio valor binario.

  • ✅ Recuerda la posición aunque se apague.
  • Su resolución se mide en bits: 10 bits = 2¹⁰ = 1024 posiciones.
  • Usa más sensores y un disco con patrón binario (código Gray).

¿Cómo funciona uno óptico?

1

Un disco con ranuras gira junto al eje.

2

Un LED apunta hacia el disco.

3

Las ranuras dejan pasar o bloquean la luz al girar.

4

Un fotodetector convierte los destellos en pulsos eléctricos.

5

El microcontrolador cuenta los pulsos = cuánto giró. Con los canales A y B sabe hacia dónde.

Aplicaciones (voltea las tarjetas 🃏)

🖱️ Rueda del mouse
Un encoder incremental detecta el giro de la rueda de scroll.
🤖 Robótica
Cada articulación usa un encoder absoluto para saber su posición exacta.
🖨️ Impresoras 3D y CNC
Controlan la posición precisa de los ejes de movimiento.
🔊 Perillas de audio
Girar una perilla digital de volumen es usar un encoder incremental.

Ejemplo en Arduino (KY-040)

// Encoder rotatorio KY-040: cuenta posiciones del giro
int contador = 0;
int ultimoCLK;

void setup() {
  pinMode(2, INPUT);  // CLK (canal A)
  pinMode(3, INPUT);  // DT  (canal B)
  Serial.begin(9600);
  ultimoCLK = digitalRead(2);
}

void loop() {
  int clk = digitalRead(2);
  if (clk != ultimoCLK && clk == HIGH) {      // flanco de subida
    if (digitalRead(3) != clk) contador++;    // DT distinto = giro horario
    else                       contador--;    // giro antihorario
    Serial.println(contador);
  }
  ultimoCLK = clk;
}

Conexiones: CLK→2, DT→3, +→5V, GND→GND. Abre el Monitor Serial y gira el encoder: verás el contador subir y bajar. 🔄
